2.2.1

DD Month 2026

Version 2.2.1 is a major update packed with new tools, big performance gains, and a more polished interface since 1.1.2.

New tools

  • Largest Files view, File Age chart (click a bucket to reveal those files in Explorer)
  • Verified duplicate finder (SHA256), snapshot compare for tracking growth over time
  • HTML export, CSV export and re-import

Faster scanning

  • Scan speed dramatically improved on large drives (fixed a bug that could leave scans running effectively single-threaded)
  • Parallel multi-drive scanning, pre-scan include/exclude filters
  • Long file path and Alternate Data Stream support, drag a folder in to scan it
  • Hard-link-aware size-on-disk reporting

Bulk actions

  • Select files by filter, then delete or move in bulk
  • Bulk find-and-replace renaming

Better visuals

  • Customizable category colors (presets + hue shift) across every chart
  • Live category coloring in the file list
  • Windows taskbar progress indicator and on-screen scan timer

Interface

  • Resizable, scrollable Settings that adapts to any window size
  • Double-click to open files, F2 to rename, Delete to Recycle Bin, copy/cut
  • Right-click "Open Command Prompt here" / Properties, advanced search filters
  • Drag files out to Explorer, export the treemap as an image

Fixes

  • Crash when cancelling a scan
  • Stale Explorer right-click entry after an update
  • Progress indicator appearing frozen when the window loses focus mid-scan
