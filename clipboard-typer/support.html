Clipboard Typer — Support

Last updated 2 October 2026

Email Hio-Mitos@gladiators.city and you'll get a reply, usually within a few days.

Please don't paste clipboard contents you wouldn't want someone else to read — they are never needed to help you.

Before you write in

It helps to include your Windows version, the Clipboard Typer version, what you did, what you expected and what happened instead.

Common questions

My clipboard history disappeared.

That's by design. The history is kept in memory only, so it's cleared whenever the app closes or your PC restarts. Nothing is ever written to disk.

A shortcut doesn't work.

Another app may already be using that key combination. When you customise a shortcut that's already taken, Clipboard Typer tells you so — choose a different one in its settings.

The shortcuts don't respond in one particular app.

Windows doesn't let an app send keystrokes into a window that is running as Administrator unless it is running as Administrator too. If the shortcuts work everywhere except one program, check whether that program was started as Administrator.

It doesn't start after I restart my PC.

Make sure Run at startup is on in Clipboard Typer, and that it isn't switched off in Windows Settings → Apps → Startup. If Windows has it turned off, the app tells you and offers a direct way to fix it. Version 1.3.0 also fixed a bug that stopped run at startup from working reliably, so make sure you're up to date.

How do I stop it while it's typing?

Press and hold Esc to cancel typing partway through.

Why type instead of paste?

Some places refuse a paste — remote sessions, certain login fields and consoles. Typing the text out as keystrokes works there too.

Reporting a security issue

If you believe you've found a vulnerability, email Hio-Mitos@gladiators.city with the details and please hold off on publishing until it's fixed.
