Space Analyzer

See what's using your storage space

Space Analyzer scans your drives and folders and shows exactly what's using your storage space, so you can find what's worth deleting. Treemaps, sunburst charts and sortable file lists stay in sync as you browse — and everything is processed on your own PC. It never uploads your data anywhere.

What it does

  • Treemap and sunburst views of any drive or folder, kept in sync with a sortable file list.
  • Largest Files view to surface the biggest files across the scan.
  • File Age chart grouping files by modification date.
  • Duplicate finder verified with SHA-256 hashes.
  • File Types breakdown with customizable colours.
  • Bulk delete, move, and find-and-replace renaming.
  • Fast parallel scanning with include/exclude filters set before the scan starts.
  • Accurate size-on-disk reporting for compressed, sparse and hard-linked files.
  • Snapshot comparison to track how a drive grows over time.
  • Export to HTML reports, CSV, or a PNG image of the treemap.

Privacy in one line

Space Analyzer makes no network connections and collects nothing. The full details are in the privacy policy.
