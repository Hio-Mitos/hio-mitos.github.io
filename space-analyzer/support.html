Space Analyzer — Support

Help, bug reports and common questions

Contact: Hio-Mitos@gladiators.city

That address reaches us from every version of the app — Microsoft Store, sideloaded, or development. There is no separate support queue depending on how you installed it.

The quickest way to report a problem

Open Settings → Feedback & support → Send feedback in the app. That opens a new email already filled in with your app version, Windows version and CPU architecture — the details that are needed to reproduce almost any bug, and that are tedious to look up by hand. You can edit or delete any of it before sending.

If no email application is set up on your PC, use Copy details instead and paste it into webmail.

What to include

A report is much easier to act on with:

  • What you were doing, and what happened instead.
  • Which drive or folder you were scanning, and roughly how large it is.
  • Whether it happens every time, or only sometimes.
  • If the app closed unexpectedly: the contents of %LOCALAPPDATA%\SpaceAnalyzer\crash.log. Paste the path into File Explorer's address bar to find it. The file is never sent anywhere automatically — attaching it is entirely your choice.

Common questions

A scan is taking a very long time.

Scan time depends on the number of files far more than on how much data there is — a drive with a million small files takes much longer than one with a few large ones. Two things help significantly:

  • Turn on Fast NTFS scan in Settings and run the app as Administrator. It reads the drive's index directly instead of walking folders one at a time, which is dramatically faster. If it cannot be used, the app now tells you why after the scan.
  • Add an exclusion for C:\Windows\WinSxS under Settings → exclude patterns. It is one of the densest folders on a typical Windows drive and is rarely what you are looking for.

The totals don't match what File Explorer shows.

Space Analyzer reports size on disk — what the files actually occupy, including cluster rounding and NTFS compression — which is usually what matters when freeing up space. It also avoids counting hard-linked files more than once, which Explorer does count repeatedly. You can turn Exact size on disk off in Settings to compare.

Some folders show as "Restricted".

Those are folders Windows did not allow the app to read, typically other users' profiles or protected system folders. Running as Administrator reveals most of them. Their contents are not included in the totals.

I deleted something in File Explorer and the app still shows it.

A scan is a snapshot. The app notices changes in the area you scanned and offers a Sync changes button, which rescans only the folders that actually changed rather than the whole drive.

Where are my settings stored?

%LOCALAPPDATA%\SpaceAnalyzer\. Deleting that folder resets the app to defaults. Settings → Reset settings to default does the same thing from inside the app.

Privacy

Space Analyzer makes no network connections, has no accounts, and collects nothing. Full details are in the privacy policy.

Reporting something security-sensitive

If you believe you have found a security issue, please email the address above with "security" in the subject line and give us a reasonable opportunity to fix it before disclosing it publicly.
