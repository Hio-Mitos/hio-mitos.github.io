Space Analyzer — Privacy Policy

Effective 1 September 2026 · Applies to Space Analyzer for Windows, version 2.2.1.0 and later

Space Analyzer is a local, offline disk-usage tool. It scans drives and folders on your own computer and shows you what is using your storage space. Space Analyzer does not collect, transmit, sell, or share any personal data. It makes no network connections of any kind — there is no telemetry, no analytics, no advertising, no account system, and no cloud service involved in its operation.

This policy explains, in plain terms, exactly what data the app touches, where it's stored, and why — so you don't have to take that on faith.

What data the app never collects

Space Analyzer does not collect or transmit:

  • Your name, email address, or any other personal or contact information.
  • The names, paths, contents, or metadata of your files, sent anywhere off your device.
  • Usage statistics, crash reports, or diagnostic data sent to us or any third party.
  • Location data, device identifiers, or advertising identifiers.
  • Any information at all over the internet. The app makes no outbound network requests.

There is no account or sign-in system, and no license key that phones home. The app functions identically whether or not your computer is connected to the internet.

What data the app reads

To do its job, Space Analyzer reads the file and folder structure of drives or folders you choose to scan — file names, sizes, dates, and types — purely to calculate and display storage usage. This information is read directly from your computer's file system using standard Windows APIs and is used only to build the on-screen results (treemap, sunburst chart, file list, and related views). It is never sent anywhere.

What data the app stores locally, and where

Everything Space Analyzer stores stays on your own computer, in locations you control:

  • Settings: your preferences (theme, color palette, scan options, and similar) are saved to a configuration file under %LOCALAPPDATA%\SpaceAnalyzer\.
  • Crash log: if the app encounters an unexpected error, a local log describing what happened is written to %LOCALAPPDATA%\SpaceAnalyzer\crash.log, purely so you (or, if you choose to share it, someone helping you troubleshoot) can review it. This file is never transmitted automatically — it stays on your machine unless you decide to send it somewhere yourself.
  • Exports you create: if you choose to export scan results (as CSV, an HTML report, or a PNG image of the treemap), that file is written only to the location you pick when saving it. Nothing is uploaded as part of exporting.
  • Snapshots: if you use the snapshot-compare feature to track changes over time, those snapshots are the CSV files described above, stored wherever you saved them.
  • Windows Registry: if you enable the optional "Analyze the folder" right-click integration in Explorer, the app writes a small entry to your Windows Registry (under HKEY_CURRENT_USER) so that menu option appears. This contains no personal data and can be removed at any time by disabling the setting.
  • Clipboard: copy/cut actions you initiate within the app place file paths or file data on your local Windows clipboard, the same as any other Windows application's copy/cut feature.

None of the above is ever synced, backed up, or transmitted to us or to any third party by the app itself. If you use a cloud-synced folder (such as OneDrive) as the location you scan or save exports to, that folder's own sync behavior is controlled by Windows and your cloud provider, not by Space Analyzer.

Local Windows features the app uses

A few features work by asking Windows itself to do something locally, rather than by Space Analyzer contacting a server:

  • File Explorer integration: actions like "Open Command Prompt here," viewing file Properties, or opening a file all hand off to Windows' own Explorer/shell — the same as double-clicking a file normally would.
  • Windows Search: the "reveal in Explorer" actions (for example, jumping from the File Age chart to matching files) construct a local search-ms: search query and open it in Explorer's built-in search. This uses Windows' own local search indexer on your device; it does not send your file information to Microsoft or any other online service.

Children's privacy

Space Analyzer is a general-purpose utility not directed at children and does not knowingly collect any information from anyone, regardless of age — because it does not collect information from anyone at all.

Changes to this policy

If this policy ever changes — for example, if a future version adds an optional, clearly-disclosed feature that does transmit data (such as an opt-in crash-reporting service) — this page will be updated with a new effective date, and any such feature will be off by default and clearly explained before you turn it on.
