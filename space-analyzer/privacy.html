Space Analyzer — Privacy Policy

Effective 2 October 2026 · Applies to Space Analyzer for Windows, version 2.3 and later

Space Analyzer is a local, offline disk-usage tool. It scans drives and folders on your own computer and shows you what is using your storage space. Space Analyzer does not collect, transmit, sell, or share any personal data. It makes no network connections of any kind — there is no telemetry, no analytics, no advertising, no account system, and no cloud service involved in its operation.

This policy explains exactly what data the app touches, where it is stored, and why — so you do not have to take that on faith.

What the app never collects

Space Analyzer does not collect or transmit:

  • Your name, email address, or any other personal or contact information.
  • The names, paths, contents, or metadata of your files, sent anywhere off your device.
  • Usage statistics, crash reports, or diagnostic data sent to us or any third party.
  • Location data, device identifiers, or advertising identifiers.
  • Any information at all over the internet. The app makes no outbound network requests.

There is no account or sign-in, and no licence key that phones home. The app works identically whether or not your computer is connected to the internet.

What the app reads

To do its job, Space Analyzer reads the file and folder structure of drives or folders you choose to scan — file names, sizes, dates, and attributes — purely to calculate and display storage usage. This is read directly from your computer's file system using standard Windows APIs and is used only to build the on-screen results. It is never sent anywhere.

What the app stores, and where

Everything Space Analyzer stores stays on your own computer:

  • Settings — your preferences (theme, colour palette, scan options, which views are shown) are saved to a configuration file under %LOCALAPPDATA%\SpaceAnalyzer\. If you used a version released before the app was renamed, your existing settings folder is moved to this location the first time you run the new version.
  • Crash log — if the app hits an unexpected error, a local log describing it is written to %LOCALAPPDATA%\SpaceAnalyzer\crash.log, so that you (or someone helping you troubleshoot) can read it. This file is never transmitted automatically. It stays on your machine unless you choose to send it yourself.
  • Exports you create — if you export scan results as CSV, as an HTML report, or as a PNG image, that file is written only to the location you pick when saving it. Nothing is uploaded as part of exporting.
  • Snapshots — the snapshot-compare feature uses the CSV files described above, stored wherever you saved them.
  • Windows Registry — if you turn on the optional "Analyze the folder" right-click entry, the app writes a small entry under HKEY_CURRENT_USER so that option appears in File Explorer. It contains no personal data and is removed when you turn the feature off.
  • Clipboard — copy and cut actions you initiate place file paths or file data on your local Windows clipboard, exactly as any other Windows application's copy/cut does.

None of this is synced, backed up, or transmitted by the app. If you choose to scan or save into a cloud-synced folder such as OneDrive, that folder's own syncing is controlled by Windows and your cloud provider, not by Space Analyzer.

Watching for changes on disk

After a scan, Space Analyzer can notice when files or folders are added, removed, or renamed inside the area you scanned, so it can offer to refresh the affected folders rather than making you rescan everything.

This uses a standard Windows notification facility that reports changes to the app as they happen on your own machine. The app only ever learns that something in a folder changed; nothing is recorded to disk and nothing is transmitted. No rescan happens until you ask for one.

Local Windows features the app uses

Some features work by asking Windows to do something locally, rather than by contacting any server:

  • File Explorer integration — "Open Command Prompt here", viewing Properties, revealing a file, or opening a file all hand off to Windows' own shell, exactly as double-clicking would.
  • Windows Search — the "reveal in Explorer" actions build a local search query and open it in Explorer's built-in search. This uses Windows' own search index on your device; it does not send your file information to Microsoft or anyone else.

Sending feedback

Settings includes a "Send feedback" button. It opens a new message in your own email application, pre-filled with the support address, your app version, your Windows version and build, your CPU architecture, and the Python/Qt versions the app is built on. It contains no file paths, no file names, no user name, and nothing from your scans.

You see this message before anything is sent, you can edit or delete any part of it, and nothing is sent unless you send it yourself. The app does not transmit the message — your email application does. If you prefer, a "Copy details" button puts the same text on your clipboard instead.

Email you choose to send to the support address is received and read solely to answer you and to fix problems. It is not used for marketing and is not shared with anyone else.

Children's privacy

Space Analyzer is a general-purpose utility, is not directed at children, and does not knowingly collect information from anyone of any age — because it does not collect information from anyone at all.

Changes to this policy

If this policy changes — for example, if a future version adds an optional feature that does transmit data — this page will be updated with a new effective date, and any such feature will be off by default and clearly explained before you turn it on.
